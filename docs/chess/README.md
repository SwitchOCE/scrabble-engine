# Chess-engine techniques

One file per technique (e.g. `nnue.md`, `search.md`, `testing-sprt.md`): what it is, Elo gained, how it maps to Scrabble. See research track R3.

- [stockfish-commit-stats.md](stockfish-commit-stats.md): every Stockfish commit parsed into result, Elo, area and technique (generated by `scripts/parse-stockfish-commits.py`).
- [nnue.md](nnue.md): Stockfish's move to NNUE (architecture history, accumulator, quantisation, training data and loss, measured payoffs) and what transfers to a Scrabble sim-leaf value net, with a per-eval cost target.
- [testing-method.md](testing-method.md): SPRT on fishtest (bounds history, normalized Elo, pentanomial pairs, STC/LTC ladder, non-regression) and a proposed paired-bag SPRT ladder for our CPU budget.
- [ranked-ideas.md](ranked-ideas.md): the top Stockfish techniques by measured Elo, each marked transfers / partly / doesn't.
